# 从工具基础，到一套会运转的知识资产工作流。

<p class="learning-reader-lead">从一个重复问题出发，找对资料、写出有出处的答复，再把稳定步骤整理成 SOP。五门课程共用一套虚构答疑资料，你可以先照着做一遍，再换成自己的任务。</p>

## 学习方式 {#method}

<div class="learning-method-card">
  <span>一级课程</span><b>选择一个完整学习主题</b><i>→</i><span>二级课时</span><b>每次完成一个明确目标</b><i>→</i><span>业务结果</span><b>用真实成果检验是否学会</b>
</div>

<p><strong>想先试一遍？</strong> <a href="/learning/knowledge-ai/first-loop#practice">直接做 30 分钟答疑练习</a>。想系统学习，可以从下面第一门课开始。</p>

## 推荐学习顺序 {#order}

<div class="learning-order-list">
  <p><i>01</i><span><b>先建立全局地图</b>理解执行层、知识层与方法层，不把工具功能等同于知识系统。</span></p>
  <p><i>02</i><span><b>再分别学会执行与检索</b>用 WorkBuddy 完成任务，用 IMA 保存、检索并核对资料依据。</span></p>
  <p><i>03</i><span><b>最后完成联动与沉淀</b>让知识进入业务流程，经过人工审核后回存，并形成可复用 SOP。</span></p>
</div>

## 完成五门课程后，你会留下什么 {#outcomes}

<p>学习成果不是平台里的“已读”状态，而是五组可以继续用于真实业务的知识资产。</p>

<div class="learning-outcome-grid">
  <article><span>00</span><h3>任务与资料包</h3><p>一张真实任务卡，以及经过命名、来源和权限检查的最小资料包。</p></article>
  <article><span>01</span><h3>第一次执行结果</h3><p>一张可复用任务说明，以及一份经过人工验收的AI执行结果。</p></article>
  <article><span>02</span><h3>最小知识库</h3><p>一组可检索资料，以及引用、版本、审核状态和维护记录。</p></article>
  <article><span>03</span><h3>第一次知识联动</h3><p>一套最小7库地图，以及一次生成、审核、评价和回存闭环。</p></article>
  <article><span>04</span><h3>SOP与维护机制</h3><p>一份经过复现的SOP、一张Skill准入表和一套知识维护节奏。</p></article>
</div>

## 完成标准 {#completion}

完成学习不是看完全部文字，而是交付可以检查的真实结果。每一课都包含“本课交付物”和“完成标准”；只有成果能够说明输入、知识依据、人工判断和下一次复用位置，才算真正完成。

<div class="learning-completion-rule"><span>完成一课</span><b>产出成果</b><i>→</i><b>逐项验收</b><i>→</i><b>保存依据</b><i>→</i><b>进入下一课</b></div>
