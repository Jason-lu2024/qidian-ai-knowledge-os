## 从搭建到长期运转的四个阶段

<p>7库解决“知识应该沉淀什么”，AI联动解决“知识怎样产生业务结果”。要让系统长期可信，还需要把治理和维护放进同一个闭环。</p>

<div class="method-lifecycle">
  <article><span>01 / BUILD</span><h3>建设</h3><p>选择一个高频业务场景，盘点现有资料，建立最小7库、基础字段和验收范围。</p><b>交付信号：资料有归属，结构能支持第一个任务。</b></article>
  <article><span>02 / ACTIVATE</span><h3>调用</h3><p>由真实任务驱动跨库调用，让知识进入内容、销售、答疑、方案、SOP和培训。</p><b>交付信号：能生成一项有依据、可检查的结果。</b></article>
  <article><span>03 / GOVERN</span><h3>治理</h3><p>为关键知识保留来源、版本、适用范围、审核状态和人工责任，避免错误内容进入业务。</p><b>交付信号：关键判断可追溯，对外内容可审核。</b></article>
  <article><span>04 / MAINTAIN</span><h3>维护</h3><p>根据业务反馈处理新增、过期、重复与缺口，让优质结果持续回存并成为下一次标准。</p><b>交付信号：知识有人维护，变化能够被发现。</b></article>
</div>

<div class="method-delivery-boundary">
  <div><span>公开方法</span><h3>讲清结构、流程与验收标准</h3><p>你可以通过学习路径理解7库分工、AI联动和基本治理原则，并完成一个最小练习闭环。</p></div>
  <div><span>企业交付</span><h3>按真实业务完成设计、搭建与移交</h3><p>企业知识盘点、7库映射、字段与模板、权限和审核、工作流配置、团队培训与验收，由项目交付完成。</p></div>
</div>

## 一个框架，不等于七个同名文件夹

<p>7库首先是一套业务知识语义框架，用来判断知识在业务中承担什么角色。个人IP可以直接使用七个同名目录；企业则应根据业务场景、流程、部门、权限和现有工具选择实际结构。</p>

<div class="architecture-grid">
  <article><span>01</span><h3>完整7库型</h3><p>适合业务边界清楚、资料量适中，需要快速形成统一语言的小团队。</p><b>七库可作为主要物理目录</b></article>
  <article><span>02</span><h3>最小试点型</h3><p>先围绕一个高频场景建立3—4个必要知识域，跑通闭环后再扩展。</p><b>七库用于识别暂缺内容</b></article>
  <article><span>03</span><h3>业务域型</h3><p>按市场、销售、交付、客服等业务域组织，七库作为标签或索引。</p><b>适合跨部门业务知识</b></article>
  <article><span>04</span><h3>流程型</h3><p>按获客、成交、交付、复购等关键流程组织，知识跟随任务进入工作。</p><b>适合流程驱动型组织</b></article>
  <article><span>05</span><h3>部门权限型</h3><p>以部门和权限为物理边界，再使用七库字段统一知识类型。</p><b>适合敏感资料较多的企业</b></article>
  <article><span>06</span><h3>混合型</h3><p>业务域、流程、权限与七库标签组合使用，由诊断形成正式架构决策。</p><b>适合复杂度较高的团队</b></article>
</div>

<div class="architecture-decision-note"><span>企业搭建的必要产物</span><div><h3>《知识架构决策记录》</h3><p>明确为什么采用某种结构、七库分别位于物理层还是标签层、哪些内容暂不纳入，以及权限、责任人与后续扩展方式。</p></div><a href="/services/#diagnosis">了解知识资产诊断 →</a></div>

## 七个库的主要输入与输出

| 知识库 | 主要输入 | 主要输出 |
| --- | --- | --- |
| 定位库 | 业务选择、优势、边界、价值主张 | 品牌介绍、表达口径、选题边界 |
| 客户库 | 访谈、咨询记录、客户语言、决策原因 | 用户画像、场景判断、销售洞察 |
| 问题库 | 高频提问、异议、搜索词、业务卡点 | 选题池、FAQ、需求优先级 |
| 素材库 | 故事、数据、截图、观点、案例证据 | 内容论据、案例片段、表达素材 |
| 方法库 | 复盘、步骤、标准、清单、框架 | SOP、课程结构、操作指南 |
| 产品库 | 服务说明、范围、价格、常见异议 | 销售方案、产品说明、答疑口径 |
| 高分样本库 | 经过审核的文章、方案、答复与反馈 | 质量标准、风格参照、复用模板 |
